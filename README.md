# -RatioCropTool
比例截图裁剪工具 RatioCropTool  一款基于 Python + PyQt5 + Pillow 开发的轻量级截图与图片裁剪工具，核心能力为**固定宽高比例锁定裁剪**。全程采用物理像素级处理机制，保证输出画质与原始画面完全一致。支持屏幕截图裁剪与本地图片导入裁剪双模式，适配 Windows 高 DPI 缩放与多显示器环境，界面采用柔和派生配色，简洁易用。

## 核心特性
- ✂️ **比例锁定裁剪**：预设 1:1 / 4:3 / 11:9 / 16:9 / 3:2 常用比例，支持自定义比例与自由比例；拖拽选区四边、四角、整体移动均严格保持设定比例，整数比例对齐确保输出比例无偏差
- 🖼️ **双工作模式**：全屏截图裁剪 + 本地图片导入裁剪，两套模式复用同一套比例控制与裁剪逻辑，功能一致
- 🎯 **原生无损画质**：屏幕捕获物理像素、图片读取原始像素、裁剪为像素级切片，全程无缩放、无插值、无模糊；PNG 格式无损输出，画质与原图完全一致
- 🖥️ **高 DPI 适配**：Windows 端开启 Per-Monitor V2 DPI 感知，支持 100% / 125% / 150% 系统缩放，截图坐标精准、画面清晰不虚
- 🖥️ **多显示器支持**：完整捕获虚拟桌面画面，跨屏坐标统一映射，适配多屏混合分辨率场景
- ⌨️ **快捷交互**：回车 / 双击确认裁剪，Esc 取消操作；结果支持保存为本地 PNG 文件、一键复制到系统剪贴板

## 使用说明

### 主界面操作

1. **选择裁剪比例**：通过下拉框选择预设比例；选择「自定义」后可手动输入宽高数值；选择「自由比例」则取消比例锁定
2. **开始截图**：点击后自动隐藏主窗口，进入全屏截图模式
3. **导入图片裁剪**：选择本地图片文件（支持 PNG/JPG/BMP/WebP 等格式），进入图片裁剪模式

### 裁剪交互

- **创建选区**：在画面上按住鼠标左键拖拽，生成对应比例的裁剪选区
- **移动选区**：鼠标置于选区内部按住拖拽，整体平移选区位置
- **调整大小**：鼠标置于选区四边 / 四角，按住拖拽调整尺寸，全程保持设定宽高比
- **确认裁剪**：按 `回车键` 或 双击选区，完成裁剪并弹出结果窗口
- **取消操作**：按 `Esc` 键，退出裁剪模式返回主界面

### 结果处理

- 预览裁剪结果，查看实际像素尺寸与色彩模式
- **保存为 PNG**：无损保存到本地路径，全透明图片自动保留 Alpha 通道
- **复制到剪贴板**：一键复制裁剪结果，可直接粘贴到文档、聊天框等其他应用
